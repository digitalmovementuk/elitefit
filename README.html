Keep the plan in sync

The plan’s source file is plan-data.json. Update this file first, then regenerate the plan with _build/build_deck.py.

This keeps the timeline, monthly view, task list and exported documents consistent. The plan folder contains the HTML, Markdown and PDF versions, plus tasks.csv.

Working together

Put each file in its matching folder. Mark its status as draft, review or approved in the filename or nearby README. Collect feedback in one place, and record decisions in project-management/decisions/.

Team members with write access can add, edit and upload files through GitHub. Follow the contribution guide for the simple steps.

This repository is public. Keep passwords, access tokens and customer records out of it. Publishing changes to the live client website needs separate approval.

After changing the plan, the build script updates HTML, Markdown and CSV. Use Print / PDF in the updated presentation to refresh the PDF copies.

Operations only

Do not upload agency prices, fees, margins, commercial proposals, quotes or owner decks containing prices here. Keep those files in the separate private Sales workspace. A folder inside this repository cannot restrict access.

EliteFit’s customer-facing pass and membership prices may appear when needed for website implementation.
