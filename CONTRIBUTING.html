How to add or change work

Use this guide when adding designs, copy, code or project files to the EliteFit workspace.

Add a file on GitHub

  1. Open the repository and choose the matching folder from the folder guide.
  2. Choose Add file → Upload files, or open an existing text file and choose the pencil icon to edit it.
  3. Give the file a clear name. Add draft, review or approved to its name, or record the status in the folder’s README. Use approved only after approval has been given.
  4. Describe the change in a short commit message, such as “Add draft membership page copy”. A commit saves the change in the project’s history.
  5. Save the change. You can work directly on main or use a feature branch for a separate piece of work.

Keep each commit focused on one small change. For a newer version, keep the previous version available for reference.

Ask for feedback

Keep feedback for each item in one shared place. Design feedback belongs in design/feedback/; record agreed project decisions in project-management/decisions/. Link to the exact file or version so everyone reviews the same work.

Change the project plan

Edit plan-data.json, then regenerate the plan using _build/build_deck.py. Include the updated source and generated files in the same change so the timeline, monthly view and task list agree.

Edit the Word plan

Download the editable Word plan from the project guide. Team members can edit its text, tables and Gantt cells in Word. Use Comments or Track Changes for proposed changes, then upload the updated file here. Betzy records agreed changes in plan-data.json so the online plan and task list stay aligned. Preserve team edits before running _build/build_word.py, which replaces the Word file.

Before saving

Open the changed file and check that it reads correctly and its links work. This is a public repository: never upload passwords, access tokens or customer records.

Saving work to GitHub does not approve publication to the live client website. Get separate approval before publishing there.

After changing the plan, the build script updates HTML, Markdown and CSV. Use Print / PDF in the updated presentation to refresh the PDF copies.

Operations only

Do not upload agency prices, fees, margins, commercial proposals, quotes or owner decks containing prices here. Keep those files in the separate private Sales workspace. A folder inside this repository cannot restrict access.

EliteFit’s customer-facing pass and membership prices may appear when needed for website implementation.

Historical reference documents

Use the reference catalogue to find imported research, design, copy and technical documents. These files record earlier work; the current project plan wins when dates or scope differ. Make new working changes in the matching active project folder and link back to a historical reference when useful. Keep the imported file manifest as the record of the original import.
