# Motion audit, lane E2: the class schedule (Today strip)

Version: v2.1 — 2026-10-01 · lane E2 (Opus 5.5 max) · HTML twin: `audit-E2.html`.
Changelog: 2026-10-01 skeleton; 19:10 rows filled; 19:40 rail-in-view re-measured (r16), final phone frame time (r15) and 390 real-data recordings (r17) added; with measured results (runs r01–r15 in `_qa/v2.1/E2/`), real club timetable (`schedule.club.json`) verified.

Method. Private build `SP/lane-E2` on port 8112, every browser run through `with-browser-lock.sh`. Phone = WebKit 390x844 and 375x812 (DPR 2, touch); desktop = Chromium 1440x900. Clock mocked by shifting `Date` in an init script (no `?now`, so the minute tick runs for real): 09:30, 09:59:50 (class start 10:00), 10:30 (class on), 10:59:52 (class end 11:00), Thursday 1 Oct 2026, Bali. Frame time: Chromium CDP `Emulation.setCPUThrottlingRate 4`, rAF deltas, median of 3 runs by p95, machine load 3–5 during the runs. WebKit cannot be CPU-throttled: judged on recordings and 40 ms filmstrips. Tokens: `--e2-*` live in `assets/css/schedule.css` §8; `--m-*` are the global tokens in `motion.css`.
