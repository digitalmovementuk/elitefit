## Page-level results for E3
- Reduced motion (`r2-reduced`): Chromium 1440 identical layout and text; WebKit 390 every E3 box identical in size and x, all shifted by exactly +36 px from something above #passes (not E3), prices, titles and the live error summary identical.
- Overflow (`r6-*/run3-overflow.json`): 0 at 320 and 360 with the page scrolled to the end, the sheet open on Elite 52 weeks and on the done step.
- Stopwatch (`r5-stopwatch`): taps day 7 / membership 8 on v2.0 and v2.1 (WebKit 390 and Chromium 1440), no scroll gestures; every next control tappable after the same wait; first tap to usable confirmation WebKit 390 median 300 / 306 ms vs 277 / 275 ms (spread v2.0 259–310, v2.1 276–456, loaded machine), Chromium 1440 68 / 76 ms vs 75 / 75 ms. Settled (animations ended) +134 to +177 ms: the tick and reference roll, never blocking a tap.
- CLS: 0 in every E3 run except 0.0019 at 1440 when Playwright fill() clears error messages without key events (`.field` moves up); with real typing these are input-driven; validation code unchanged from v2.0; real typing not measured.
- Console: 0 errors; one aborted clip request (`zone-perform.mp4`, media.js) logged as requestfailed in Chromium 390.
