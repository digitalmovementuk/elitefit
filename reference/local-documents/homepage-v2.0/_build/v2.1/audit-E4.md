## New tokens and hooks (for MOTION-AND-DESIGN.md)
- data-motion `tally` (facts that slide in once; engine also matches `.visit__facts .num`, `.rec__cta .num`).
- Attributes written by motion.js: `data-m-seam` (pre|in) on sections, `data-m-tally` on primed facts, `html[data-e4-end]`, inline `--e4-cur` on `.rec`; element `.e4-prog` (progress cue).
- Tokens: `--e4-settle` (per zone), `--e4-tally-delay`, `--e4-in-t` / `--e4-in-s` (reveal keyframe), `--e4-seam`, `--e4-mark` (per zone), `--e4-ease-settle`, `--e4-at` / `--e4-from` / `--e4-cur` (Recharge levels), `--e4-bar-ink` / `--e4-bar-num`; keyframes `e4-in`, `e4-word`, `e4-ring`.
- odometer option `dir` (1 hotter / −1 colder).
- Removed from motion.js (E2 request): the schedule day-switch entrance (`onSchedRender`, `entrance`); `ef:schedule:render` is no longer listened to by motion.js. Tab pill: a second tap during the slide starts from the pill's current position.
- Removed from motion.css (E1 request): the phone hero board settle and the v2.0 menu drop (hero.css is the single source).
