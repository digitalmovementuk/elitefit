  • Measured on the render by the lanes: frame time under 4x CPU throttle (Chromium), CLS, taps and seconds, overflow, reduced-motion layout, contrast. See section 8.

2. Method and gate

  • Gate for every moving rule: html.motion-ok, set by the inline script in the template unless reduced motion or data-saver. Without it the page shows the same layout and the same information with no motion (states are ungated).
  • E1: Chromium with CDP Emulation.setCPUThrottlingRate 4 (rAF deltas), WebKit 390 / 375 stills and filmstrips. E2: private build on port 8112, WebKit 390x844 and 375x812 (DPR 2, touch), Chromium 1440x900, the clock mocked by shifting Date (09:30, 09:59:50, 10:30, 10:59:52, Thursday 1 Oct 2026, Bali), frame time median of 3 runs by p95. E3: Chromium CPU 4x with rAF deltas (p50 / p95 ms, fps), phone profile Chromium 390x844 DPR 2 touch, WebKit on stills and filmstrips. E4: Playwright 1.63, rAF deltas with CPU 4x, phone profile 390x844 DPR 2 touch with real scroll gestures, document.getAnimations() sampled every frame, look checked on WebKit 390x844 / 375x812 / 375x667 and Chromium 1440.
  • Tokens: global --m-* in assets/css/motion.css; each lane's own tokens carry its prefix (--e1-* in hero.css §5.0, --e2-* in schedule.css §8, --e3-* in shop.css, --e4-* in motion.css and the zone CSS). New tokens and hooks are listed in section 9.
